# Deployment Guide — RecruitAI (MySQL Edition)

Three pieces to deploy: a MySQL database, the Express API (Render), and the React app (Vercel).

## 1. MySQL database

Render's free tier doesn't include managed MySQL, so use one of these (all have free tiers):

- **Railway** — https://railway.app → New Project → Provision MySQL → copy the connection details from the "Connect" tab.
- **Aiven** — https://aiven.io → free MySQL plan.
- **PlanetScale** — MySQL-compatible (Vitess); note it doesn't enforce foreign keys the same way, so if you use it, run `schema.sql` with `SET FOREIGN_KEY_CHECKS=0` around the FK statements, or use Railway/Aiven instead for a closer match to the schema as written.

Once you have a host, port, user, password, and database name:

```bash
mysql -h <host> -P <port> -u <user> -p <database> < database/schema.sql
```

Then seed it (from your machine, pointed at the remote DB via `backend/.env`):

```bash
cd backend
npm run seed
```

## 2. Backend → Render

This repo includes `render.yaml` at the project root (Render's "Blueprint" format).

1. Push this project to a GitHub repo.
2. In Render: **New → Blueprint**, connect the repo. Render reads `render.yaml` and creates
   the `recruitai-backend` web service with `rootDir: backend`.
3. Fill in the env vars flagged `sync: false` in the Render dashboard:
   - `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` — from step 1
   - `GEMINI_API_KEY` — from https://aistudio.google.com/apikey
   - `CLIENT_URL` — your Vercel frontend URL (set after step 3 below; can update later)
   `JWT_SECRET` is auto-generated by Render.
4. Deploy. Confirm `GET https://<your-backend>.onrender.com/api/health` returns `{ "success": true }`.

**No Blueprint?** Manually: New → Web Service → root directory `backend` → build command
`npm install` → start command `npm start` → add the same env vars.

## 3. Frontend → Vercel

1. In Vercel: **New Project**, import the same repo, set **Root Directory** to `frontend`.
2. Vercel auto-detects Vite; `vercel.json` in `frontend/` handles SPA routing (all paths → `index.html`).
3. Add an environment variable: `VITE_API_URL` = `https://<your-backend>.onrender.com/api`.
4. Deploy. Once live, copy the Vercel URL back into the backend's `CLIENT_URL` env var on Render
   and redeploy the backend so CORS allows it.

## 4. Verify

- Visit the Vercel URL → log in with `admin@recruitai.com` / `Password123` (from the seed script).
- Check the dashboard loads data (confirms frontend ↔ backend ↔ database are all connected).
- Try the AI Resume Analyzer to confirm `GEMINI_API_KEY` is working.

## Notes

- Render's free web services spin down after inactivity — the first request after idle can take
  10–20s while it wakes up.
- Rotate `JWT_SECRET` and `GEMINI_API_KEY` if they're ever committed to a public repo.
